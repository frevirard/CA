Format source

  • A : Typologie de la ressource
  • B : Code et Nom de la ressource
  • C : Profil de la ressource
  • D : Environnement
  • E/F : Nom / Prénom
  • G à M : Société, service, référence, email, état, départ, identifiants

Référentiel groupes

  • Colonne A : Id du groupe
  • Colonnes B à n : une colonne par droit distinct
  • Question : “Voulez-vous conserver le profil … ?”
  • Colonnes finales : Formulaire créé, Date, Id formulaire, Lien consultation
  • Cellule “Inclus” : fond vert clair, gras, centré

Principes clés

  • Les séparateurs ||| et ### doivent être absents des données sources.
  • La signature est stable car elle est construite sur des droits triés.
  • Un même ensemble de droits produit toujours le même groupe.
  • La première occurrence de l’utilisateur fait foi pour les données personnelles.

Gestion des erreurs

  • Colonne manquante : message explicite et arrêt du traitement.
  • Erreur inattendue : affichage du code et du message d’erreur.
  • Fermeture propre des fichiers ouverts.
  • Aucune sauvegarde des fichiers ouverts en cas d’erreur bloquante.
